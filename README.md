## Oxidized Version Control  

# Install (HTTPS):    
```bash
git clone https://www.github.com/kasapeli/ovc.git && cd ovc && cargo install --path .
```

# Install (SSH):  
```bash
git clone git@github.com:kasapeli/ovc.git && cd ovc && cargo install --path .
```

# Usage  
-h, --help        Display help
-i, --init        Initialize repository
-s, --stage       Stage file
-c, --commit      Commit
--CLEAN           Uninitialize/clean repository
